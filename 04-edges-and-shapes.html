Why this chapter mattersچرا این فصل مهم است؟

A robotic arm about to pick up a part needs to know exactly where that part's boundary is, where its center is, and how big it is. All of that is extracted from an image's "shape," not from raw pixel colors. This chapter walks that exact path: from changes in brightness, to edges, to measurable geometric shapes. یک بازوی رباتیک برای برداشتن یک قطعه باید بداند «مرز» آن قطعه دقیقاً کجاست، مرکزش کجاست، و اندازه‌اش چقدر است. این‌ها همه از روی «شکل» تصویر استخراج می‌شوند، نه از روی رنگ خام پیکسل‌ها. این فصل دقیقاً همین مسیر را طی می‌کند: از تغییرات روشنایی، به لبه، و از لبه به شکل هندسی قابل‌اندازه‌گیری.

1.What Is an Edge?لبه (Edge) یعنی چه؟

An edge[1] is a place in the image where brightness changes sharply and quickly, for example, the boundary between a bright object and a dark background. If we picture the image as a height map where each point's elevation equals its pixel brightness, edges are exactly the places where that map suddenly gets steep, a cliff. یک لبه[۱] جایی در تصویر است که روشنایی به‌شدت و به‌سرعت تغییر می‌کند، مثلاً مرز بین یک شیء روشن و پس‌زمینهٔ تیره. اگر تصویر را مثل یک نقشهٔ ارتفاعی تصور کنیم که ارتفاع هر نقطه برابر روشنایی پیکسل است، لبه‌ها همان جاهایی هستند که این نقشه ناگهان تند می‌شود، یک پرتگاه.

Edges matter a lot because they almost always form the backbone of an object's shape, the border of a box, the line of a road, the edge of an industrial part. لبه‌ها اهمیت زیادی دارند چون تقریباً همیشه اسکلت اصلی شکل یک شیء را می‌سازند، مرز یک جعبه، خط یک جاده، لبهٔ یک قطعهٔ صنعتی.

2.Image Gradientگرادیان تصویر (Gradient)

The Gradient[2] is the image's derivative, "how much brightness changes relative to the neighboring pixel", along two directions, x (horizontal) and y (vertical): Gradient[۲] یعنی مشتق تصویر، یعنی «چقدر روشنایی نسبت به پیکسل مجاور تغییر می‌کند», نسبت به دو جهت x (افقی) و y (عمودی):

$$ G_x = \frac{\partial I}{\partial x}, \quad G_y = \frac{\partial I}{\partial y} $$

To combine these two values into one number representing "edge strength," we use the gradient magnitude[3]: برای ترکیب این دو مقدار در یک عدد واحد که «قدرت لبه» را نشان بدهد، از اندازهٔ گرادیان[۳] (Magnitude) استفاده می‌کنیم:

$$ G = \sqrt{G_x^2 + G_y^2} $$

And if we want to know which direction the edge runs (horizontal, vertical, or diagonal), we use the gradient angle: و اگر بخواهیم بدانیم لبه در چه جهتی قرار دارد (افقی، عمودی، یا مورب)، از زاویهٔ گرادیان استفاده می‌کنیم:

$$ \theta = \arctan\left(\frac{G_y}{G_x}\right) $$
Simple numeric example:مثال عددی ساده: consider a row of pixels with values [10, 10, 200, 200].یک ردیف پیکسل با مقادیر [10, 10, 200, 200] را در نظر بگیر.

The difference between the second pixel (10) and the third (200) is 200 − 10 = 190, a huge jump. That means there's a strong edge exactly there (between pixels 2 and 3). By contrast, the difference between the first and second pixels is zero (both 10), meaning no edge there at all. تفاضل بین پیکسل دوم (۱۰) و پیکسل سوم (۲۰۰) برابر 200 − 10 = 190 است، یک تغییر بسیار بزرگ. این یعنی دقیقاً همان‌جا (بین پیکسل دوم و سوم) یک لبهٔ قوی داریم. در مقابل، تفاضل بین پیکسل اول و دوم صفر است (هر دو ۱۰), یعنی آنجا هیچ لبه‌ای نیست.

3.Sobel OperatorSobel Operator

Computing an exact derivative on a discrete (pixelated) image isn't really possible, so we use a practical approximation instead: Sobel[4], two fixed 3×3 kernels, one for estimating $G_x$ and one for $G_y$, applying the same convolution idea from the previous chapter. محاسبهٔ دقیق مشتق روی یک تصویر گسسته (پیکسلی) عملاً ممکن نیست، پس از یک تقریب عملی استفاده می‌کنیم: Sobel[۴], دو کرنل ۳×۳ ثابت، یکی برای تخمین $G_x$ و یکی برای $G_y$، که همان ایدهٔ Convolution فصل قبل را به کار می‌گیرند.

sobelx = cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=3)
sobely = cv2.Sobel(gray, cv2.CV_64F, 0, 1, ksize=3)

The parameters 1, 0 mean "first-order derivative with respect to x, zero-order with respect to y" (i.e., give just $G_x$). The reverse is used for $G_y$. Combining both outputs (per the Magnitude formula above) lets us build a complete map of edge strength. پارامترهای 1, 0 یعنی «مشتق مرتبهٔ اول نسبت به x، مرتبهٔ صفر نسبت به y» (یعنی فقط $G_x$ را بده). برعکسش برای $G_y$ استفاده می‌شود. با ترکیب این دو خروجی (طبق فرمول Magnitude بالا) می‌توانیم نقشهٔ کامل قدرت لبه‌ها را بسازیم.

Try It Yourself, Exercise 1امتحانش کن، تمرین ۱

Compute the gradient of a simple image with Sobel and look at its magnitude:گرادیان یک تصویر ساده را با Sobel حساب کن و اندازه‌اش را ببین:

import cv2, numpy as np
gray = cv2.imread("shape.jpg", cv2.IMREAD_GRAYSCALE)
sobelx = cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=3)
sobely = cv2.Sobel(gray, cv2.CV_64F, 0, 1, ksize=3)
magnitude = np.sqrt(sobelx**2 + sobely**2)
magnitude = np.uint8(255 * magnitude / magnitude.max())
cv2.imwrite("gradient.jpg", magnitude)
What should I expect?چه انتظاری باید داشته باشم؟

In the output gradient.jpg, only edges (object boundaries) appear bright, while uniform regions (background, flat surfaces) stay completely black, because brightness change is near zero there. در تصویر خروجی gradient.jpg فقط لبه‌ها (مرز اشیا) روشن دیده می‌شوند و نواحی یکدست (پس‌زمینه، سطح‌های صاف) کاملاً سیاه می‌مانند، چون آنجا تغییر روشنایی نزدیک صفر است.

Stage 1, Gaussian Blur:مرحلهٔ ۱، Gaussian Blur: first we clean out noise, since noise itself produces sudden brightness changes that can be mistaken for edges.قبل از هر چیز نویز را پاک می‌کنیم، چون نویز خودش تغییرات ناگهانی روشنایی ایجاد می‌کند و می‌تواند اشتباهاً به‌عنوان لبه شناسایی شود.

Stage 2, Gradient:مرحلهٔ ۲، Gradient: using Sobel, the gradient's magnitude and direction are computed at every pixel (as we saw in the previous section).با Sobel، اندازه و جهت گرادیان در هر پیکسل محاسبه می‌شود (همان‌طور که در بخش قبل دیدیم).

Stage 3, Non-Maximum Suppressionمرحلهٔ ۳، Non-Maximum Suppression[6]: edges usually look "thick" after computing the gradient (several pixels wide). This stage moves perpendicular to the edge and keeps only the strongest pixel; the rest are zeroed. The result is an edge exactly one pixel wide. معمولاً لبه‌ها بعد از محاسبهٔ گرادیان «ضخیم» به‌نظر می‌رسند (چند پیکسل عرض دارند). این مرحله در جهت عمود بر لبه حرکت می‌کند و فقط قوی‌ترین پیکسل را نگه می‌دارد؛ بقیه صفر می‌شوند. نتیجه، لبه‌ای باریک به‌ضخامت دقیقاً یک پیکسل است.

Stage 4, Double Threshold and Hysteresisمرحلهٔ ۴، Double Threshold و Hysteresis[7]: two thresholds are defined, a high one and a low one. Pixels with gradient above the high threshold are definitely "strong edges" and kept. Pixels between the two thresholds are "weak edges" and kept only if connected to a strong edge, this chain-connection rule is called Hysteresis. دو آستانه تعریف می‌شود، یکی بالا و یکی پایین. پیکسل‌هایی که گرادیانشان بالای آستانهٔ بالا باشد قطعاً «لبهٔ قوی» هستند و نگه داشته می‌شوند. پیکسل‌های بین دو آستانه «لبهٔ ضعیف» محسوب می‌شوند و فقط در صورتی نگه داشته می‌شوند که به یک لبهٔ قوی متصل باشند، این اتصال زنجیره‌ای را Hysteresis می‌گویند.

edges = cv2.Canny(gray, 100, 200)

In this line, 100 is the low threshold and 200 the high one. These two numbers aren't universal constants, they need trial-and-error tuning on your own images: if you see too many noisy, spurious edges, raise the thresholds; if important edges are missing, lower them. در این خط، ۱۰۰ آستانهٔ پایین و ۲۰۰ آستانهٔ بالاست. این دو عدد ثابت جهانی نیستند، باید با آزمون‌وخطا روی تصویر خودتان تنظیم شوند: اگر لبه‌های زیادی نویزی و اضافی می‌بینید، آستانه‌ها را بالا ببرید؛ اگر لبه‌های مهم گم می‌شوند، پایین بیاورید.

Common Mistakeاشتباه رایج

1) Forgetting to Blur before Canny, the result fills up with noisy, irrelevant edges since noise gets mistaken for edges too. 2) Using a fixed threshold on images whose lighting changes over time (say, a mobile robot in a varying-light environment), in that case you should use Otsu or an adaptive threshold, not a fixed number that only works for one specific lighting condition. ۱) فراموش‌کردن Blur قبل از Canny, نتیجه پر از لبه‌های نویزی و بی‌ربط می‌شود چون نویز هم مثل لبه دیده می‌شود. ۲) استفاده از یک threshold ثابت روی تصاویری که نورشان در طول زمان تغییر می‌کند (مثلاً یک ربات متحرک در محیط با نور متغیر), در این حالت باید از Otsu یا adaptive threshold استفاده کرد، نه یک عدد ثابت که فقط برای یک شرایط نوری خاص کار می‌کند.

5.What Is a Contour?Contour (کانتور) چیست؟

A Contour[8] is a continuous curve that traces an object's boundary, usually extracted after edge detection or thresholding. Unlike a raw edge map (just a collection of white/black pixels), a contour is a structured object we can perform geometric calculations on: area, perimeter, center, and more. یک Contour[۸] منحنی پیوسته‌ای است که مرز یک شیء را دنبال می‌کند، معمولاً بعد از لبه‌یابی یا threshold استخراج می‌شود. برخلاف نقشهٔ خام لبه‌ها (که فقط مجموعه‌ای از پیکسل‌های سفید/سیاه است)، یک contour یک شیء ساختاریافته است که می‌توانیم رویش محاسبات هندسی انجام دهیم: مساحت، محیط، مرکز و غیره.

contours, hierarchy = cv2.findContours(edges, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
cv2.drawContours(image, contours, -1, (0,255,0), 2)

cv2.RETR_EXTERNAL means "grab only the outermost contours" (ignore contours nested inside other contours). hierarchy[9] keeps track of parent-child relationships between nested contours (for example, a ring with another contour inside it). cv2.RETR_EXTERNAL یعنی فقط بیرونی‌ترین کانتورها را بگیر (کانتورهای داخل کانتورهای دیگر را نادیده بگیر). hierarchy[۹] اطلاعات رابطهٔ پدر-فرزندی بین کانتورهای تودرتو را نگه می‌دارد (مثلاً یک حلقه که داخلش یک کانتور دیگر هم هست).

6.Extracting Geometric Features from a Contourاستخراج ویژگی هندسی از Contour

Once we have a contour, we can extract useful geometric information from it: وقتی یک contour داریم، می‌توانیم اطلاعات هندسی مفیدی از آن استخراج کنیم:

Polygon Approximation[10] with cv2.approxPolyDP approximates a many-point contour with a simpler polygon. The resulting vertex count is a good clue to the shape type: 3 vertices likely means a triangle, 4 vertices likely means a rectangle or square, and a large number of roughly equidistant-from-center vertices likely means a circle. Polygon Approximation[۱۰] با cv2.approxPolyDP کانتور پرنقطه را با یک چندضلعی ساده‌تر تقریب می‌زند. تعداد رئوس نتیجه، سرنخ خوبی برای نوع شکل است: ۳ رأس یعنی احتمالاً مثلث، ۴ رأس یعنی احتمالاً مستطیل یا مربع، تعداد زیاد رأس با فاصلهٔ تقریباً یکسان از مرکز یعنی احتمالاً دایره.

Example:مثال: if approxPolyDP returns 4 points for a contour and adjacent side lengths are roughly equal → the object is very likely a square; if side lengths differ → it's likely a rectangle. اگر approxPolyDP روی یک کانتور ۴ نقطه برگرداند و طول هر دو ضلع مجاور تقریباً برابر باشد → به احتمال زیاد آن شیء یک مربع است؛ اگر طول اضلاع متفاوت باشد → یک مستطیل.

To find the centroid[11], which is crucial for grasping, we use image moments: برای پیدا کردن مرکز جرم[۱۱] (Centroid) که برای grasping حیاتی است، از ممان‌های تصویر استفاده می‌کنیم:

M = cv2.moments(contour)
cx = int(M["m10"] / M["m00"])
cy = int(M["m01"] / M["m00"])

7.Robotics Use Caseکاربرد رباتیکی

  • Counting parts on a conveyor belt: with threshold + findContours you can count parts passing in front of the camera in real time, with no deep learning model required. شمارش قطعات روی نوار نقاله: با threshold + findContours می‌توان تعداد قطعاتی که از جلوی دوربین رد می‌شوند را در لحظه شمرد، بدون نیاز به هیچ مدل یادگیری عمیق.
  • Measuring an object's dimensions: by combining camera calibration (pixel-to-centimeter ratio) with boundingRect or contourArea, you can estimate a part's real-world dimensions. اندازه‌گیری ابعاد یک جسم: با ترکیب کالیبراسیون دوربین (نسبت پیکسل به سانتی‌متر) و boundingRect یا contourArea، می‌توان ابعاد واقعی یک قطعه را تخمین زد.
  • Finding an object's center for grasping: a robotic arm picking up an object needs to know exactly where to grip; cv2.moments gives the centroid, which is usually the best balance point to grasp. پیدا کردن مرکز شیء برای Grasping: بازوی رباتیک برای برداشتن یک شیء باید بداند دقیقاً کجا را بگیرد؛ cv2.moments مرکز جرم را می‌دهد که معمولاً بهترین نقطهٔ تعادل برای گرفتن است.

Glossaryواژه‌نامه

[1] Edge
A region in the image where brightness changes sharply; usually an object's boundary. ناحیه‌ای در تصویر که روشنایی به‌شدت تغییر می‌کند؛ معمولاً مرز یک شیء.
[2] Gradient
The image's derivative with respect to x and y; shows how quickly brightness changes in each direction. مشتق تصویر نسبت به x و y؛ نشان می‌دهد روشنایی در هر جهت چقدر سریع تغییر می‌کند.
[3] Magnitude
The overall gradient strength, combining $G_x$ and $G_y$; the larger it is, the stronger the edge. اندازهٔ کلی گرادیان، ترکیب $G_x$ و $G_y$؛ هرچه بزرگ‌تر، لبه قوی‌تر.
[4] Sobel
A 3×3 convolutional operator for practically estimating the image gradient. یک عملگر کانولوشنی ۳×۳ برای تخمین عملی گرادیان تصویر.
[5] Canny
The industry-standard edge detection algorithm, made of four stages: blur, gradient, Non-Max Suppression, and Hysteresis Thresholding. الگوریتم استاندارد صنعتی برای لبه‌یابی، شامل چهار مرحله: بلور، گرادیان، Non-Max Suppression و Hysteresis Thresholding.
[6] Non-Maximum Suppression
A stage that keeps only the strongest edge pixel in each direction so thick edges become thin. مرحله‌ای که فقط قوی‌ترین پیکسل لبه در هر جهت را نگه می‌دارد تا لبه‌های ضخیم باریک شوند.
[7] Hysteresis Thresholding
Canny's two-threshold technique that keeps weak edges only if connected to strong ones. تکنیک دو-آستانه‌ای در Canny که لبه‌های ضعیف را فقط در صورت اتصال به لبه‌های قوی نگه می‌دارد.
[8] Contour
A continuous curve that traces an object's boundary in the image. منحنی پیوسته‌ای که مرز یک شیء را در تصویر دنبال می‌کند.
[9] Hierarchy
The parent-child relationship structure between nested contours, e.g., a ring with an inner contour. ساختار رابطهٔ پدر-فرزندی بین کانتورهای تودرتو، مثلاً یک حلقه با یک کانتور داخلی.
[10] Polygon Approximation
Approximating a many-point contour with a simpler polygon to recognize the shape type. تقریب‌زدن یک کانتور پرنقطه با یک چندضلعی ساده‌تر برای تشخیص نوع شکل.
[11] Centroid (Moments)
A shape's center of mass, computed from image moments; used for precise grasping with a robotic arm. مرکز جرم یک شکل، محاسبه‌شده از ممان‌های تصویر؛ برای گرفتن دقیق شیء با بازوی رباتیک کاربرد دارد.
[12] Bounding Rect
The smallest axis-aligned rectangle enclosing the entire object. کوچک‌ترین مستطیل موازی محورها که کل شیء را در بر می‌گیرد.
